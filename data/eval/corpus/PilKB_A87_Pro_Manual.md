## 快速开始（5 分钟上手）

如果您暂时没有时间通读手册，请按本节顺序操作，即可完成开箱到输入的全流程。各步骤的详细说明在括号中标注了对应章节。

### 第 1 步：开箱与检查（约 1 分钟）

1. 打开包装，取出键盘与附件，对照第 3 章清点物品；
2. 撕除上盖缓冲膜，确认外壳、键帽、旋钮无运输损伤；
3. 从键盘顶部磁吸收纳仓中找到 2.4GHz 接收器（如需无线使用）。

### 第 2 步：选择连接方式（约 1 分钟）

| 您的设备 | 推荐方式 | 操作 |
| --- | --- | --- |
| 台式机 / 有 USB 口的笔记本 | USB-C 有线 | 线缆连接键盘与电脑，即插即用 |
| 追求桌面整洁 | 2.4G 无线 | 背面拨杆拨至 2.4G，插入接收器 |
| 平板 / 手机 / 无接收器条件 | 蓝牙 | 背面拨杆拨至 BT，长按 `<Fn> + <1>` 3 秒配对 |

### 第 3 步：验证输入（约 1 分钟）

1. 打开任意文本编辑器，逐行敲击全部按键，确认无坏键；
2. 按 `<CapsLock>` 确认 OLED 出现大小写提示；
3. 旋转右上角旋钮，确认系统音量随之变化。

### 第 4 步：按需快速设置（约 2 分钟）

| 需求 | 操作 |
| --- | --- |
| 调整灯光亮度 | `<Fn> + <W>`（升）/ `<Fn> + <S>`（降），`<Fn> + <Space>` 开关灯光 |
| 切换灯效 | `<Fn> + <E>`（下一个）/ `<Fn> + <Q>`（上一个） |
| macOS 用户 | 长按 `<Fn> + <S>`（约 3 秒）切换到 Mac 布局 |
| 游戏防误触 | `<Fn> + <Win>` 锁定 Windows 键 |
| 查看电量 | `<Fn> + <B>`，OLED 显示 5 秒 |
| 深入自定义 | 安装驱动 PilKB Console（第 11 章） |

## 1. 产品概述

### 1.1 产品简介

PilKB A87 Pro 是一款面向文字工作者、程序员与外设爱好者的 87 键（TKL / 80% 布局）三模机械键盘。键盘采用 Gasket 垫片结构装配，主 PCB 与定位板通过缓冲垫片悬挂于铝合金内胆外壳之中，配合多层消音填充，带来均匀一致、富有弹性的敲击手感与纯净的听感。

键盘同时支持 **USB-C 有线连接**、**蓝牙 5.1 无线连接（最多 3 台设备）** 与 **2.4GHz 专用无线接收器连接**，可在多台设备之间一键切换，满足办公、开发与娱乐的复合使用场景。全键支持热插拔（五脚轴座），无需焊接即可更换轴体；全键支持 RGB 背光与逐键自定义，配合 128×32 分辨率 OLED 显示屏与铝合金编码器旋钮，提供完整的可玩性与生产力扩展。

## 2. 安全须知

### 2.1 通用安全

1. 请勿将键盘放置于不稳、倾斜或振动的表面上使用，键盘跌落可能造成外壳变形、轴体脱焊或内部电池损坏。
2. 请勿拆卸、挤压、穿刺键盘外壳。键盘内部无用户可维护部件，擅自拆解将导致保修失效。
3. 请勿让液体进入键盘。虽然键帽与定位板具备一定防泼溅导流能力，但键盘**不防水**，液体渗入 PCB 将导致电路损坏。
4. 若液体不慎泼入，请立即断开有线连接 / 关闭无线电源开关，倒置键盘沥干液体，自然阴干至少 48 小时后再尝试通电。若泼入含糖饮料，请联系售后进行专业清洁。
5. 请勿将键盘暴露在高温环境中（例如夏日封闭车厢内、暖气片旁），高温会导致键帽变形、电池鼓包。
6. 请勿使用尖锐物体撬动键帽或旋钮，更换键帽请使用随附的拔键器。
7. 请勿让儿童在无人监护的情况下使用本产品。本产品包含小部件（键帽、接收器等），存在误吞风险。
8. 雷雨天气请拔下 USB-C 线缆并移除接收器，避免感应雷击通过线缆损坏设备。
9. 长时间不使用时，建议关闭键盘背面电源开关，并将电量保持在 40%–60% 后存放。
10. 清洁前请断开所有连接，清洁方法详见第 14 章。

### 2.2 锂电池安全

⚠️ 本产品内置 4000mAh 锂聚合物电池，错误使用可能引起发热、起火或爆炸。

1. 仅可使用输出规格为 5V/0.5A–2A 的标准 USB 电源适配器或电脑 USB 端口为键盘充电。
2. 严禁使用输出电压超过 5.5V 的电源（例如快充协议诱骗器）为键盘充电。
3. 充电环境温度应保持在 0 ℃ – 35 ℃ 之间。
4. 若发现键盘异常发热、鼓包、异味，请立即停止使用并联系售后服务。
5. 严禁将键盘投入火中或置于火源附近。
6. 电池不可自行更换。电池达到寿命终点后，请交由 PilKB 授权售后或当地电池回收点处理。
7. 运输时（尤其是航空运输）请将键盘电量降至 30% 以下并关闭电源开关，具体要求以承运方规定为准。
8. 长期存放时，请每 3 个月为键盘补充充电至 50% 左右，避免电池过放损坏。

### 2.3 使用环境

| 项目 | 建议范围 |
| --- | --- |
| 工作温度 | 0 ℃ – 40 ℃ |
| 存放温度 | -10 ℃ – 45 ℃ |
| 相对湿度 | 10% – 85%（无凝结） |
| 充电温度 | 0 ℃ – 35 ℃ |
| 海拔 | -500 m – 5000 m |
| 污染等级 | 2 级（一般室内环境） |

### 2.4 光敏性癫痫警告

⚠️ 本产品具备 RGB 灯光系统，部分高频闪烁灯效（例如"反应"、"扫描"等）的闪烁频率可能与光敏性癫痫的诱发频率接近。若您或您的家庭成员患有光敏性癫痫，请：

- 关闭灯光（按 `<Fn> + <↓>` 将亮度调至 0），或
- 仅使用"常亮"、"呼吸"等低频 / 静态灯效。

## 5. 产品结构与接口

### 5.1 正面布局

键盘正面从上到下分为四个区域：

| 区域 | 位置 | 内容 |
| --- | --- | --- |
| 功能区 | 顶部两行 | `<Esc>`、F1–F12 功能键行；PrtSc / ScrLk / Pause 系统键行 |
| 主键区 | 中部三行 | Tab 行（Q–P、`[`、`]`、`\`）、Caps 行（A–L、`;`、`'`、Enter）、Shift 行（Z–M、逗号、句号、`/`） |

## 6. 首次使用

### 6.1 开箱与首次检查

1. 取出键盘，撕除上盖与底壳之间的运输缓冲膜。
2. 检查外观有无运输损伤，按键有无松动。
3. 拨动背面电源拨杆至 OFF 再拨回 BT 档，确认 OLED 点亮并显示电量。
4. 建议首次使用前先将键盘充电至 100%。

❗ 键盘出厂默认电量约 50%。若 OLED 无法点亮，请先使用附赠线缆连接电脑充电 30 分钟后再试。

### 6.2 连接方式总览

| 连接方式 | 通道数 | 轮询率 | 免驱 | 适用场景 |
| --- | --- | --- | --- | --- |
| USB-C 有线 | 1 | 1000 Hz | 是 | 竞技游戏、刷写固件、充电使用 |
| 2.4GHz 接收器 | 1 | 1000 Hz | 是 | 台式机无线、低延迟场景 |
| 蓝牙 5.1 | 3 | 125 Hz | 是 | 笔记本 / 平板 / 手机多设备 |

三种模式可同时保持连接（例如：有线接台式机、蓝牙接笔记本、2.4G 接另一台设备），通过 `<Fn> + 数字键` 即时切换，切换耗时约 0.5–1 秒。

### 6.3 有线连接

1. 将附赠 USB-C 编织线的 USB-C 端插入键盘顶部端口。
2. 将 USB-A 端插入电脑。若电脑仅有 Type-C 接口，请先接上附赠的转接头。
3. OLED 显示 `USB` 即连接成功，此时同时为键盘充电。

❗ 有线模式下若背面"有线锁定开关"处于 LOCK 位，无线通道将被禁用；需要使用无线时请将该开关拨回。

### 6.4 蓝牙连接与配对

键盘提供 3 个蓝牙通道，每个通道可绑定一台设备：

1. 确认键盘电源拨杆位于 **BT** 档。
2. 长按 `<Fn> + <1>`（或 `<2>` / `<3>`）约 3 秒，对应键位蓝灯快闪，进入配对模式。
3. 打开目标设备的蓝牙设置，搜索到 **"PilKB A87 Pro"** 并点击连接。
4. 部分设备会要求输入配对码，按屏幕提示使用键盘输入 6 位数字后按 `<Enter>`。
5. 连接成功后对应键位蓝灯慢闪 3 次熄灭，OLED 显示 `BT-1`（或 `BT-2` / `BT-3`）。

短按 `<Fn> + <1>` / `<2>` / `<3>` 可在已配对的设备之间切换。

删除某通道配对：长按 `<Fn> + <1>` 约 8 秒，蓝灯快闪转长亮后熄灭，该通道配对信息被清除。

### 6.5 2.4GHz 接收器连接

1. 从键盘顶部磁吸收纳仓取出 2.4G 接收器。
2. 将电源拨杆拨至 **2.4G** 档。
3. 将接收器插入电脑 USB-A 端口，约 2 秒内自动完成连接，OLED 显示 `2.4G`。

若接收器与键盘失去配对（例如更换了接收器），请执行重新对码：

1. 保持电源在 2.4G 档，长按 `<Fn> + <4>` 约 5 秒，`<4>` 键位绿灯快闪。
2. 5 秒内将接收器重新插入 USB 端口。
3. 绿灯常亮 2 秒后熄灭表示对码成功。

### 6.6 系统布局切换（Windows / macOS）

长按 `<Fn> + <S>`（约 3 秒）在 Win 布局与 Mac 布局之间切换，OLED 会显示当前布局。两种布局下 Alt 与 Win 键的功能互换，以贴合两个系统的快捷键习惯：

| 物理按键 | Win 布局功能 | Mac 布局功能 |
| --- | --- | --- |
| 左一（Ctrl 位） | Ctrl | Control |
| 左二（Win 位） | Win | Option |
| 左三（Alt 位） | Alt | Command |
| 右三（Fn 位） | Fn | Fn |
| 右二（Menu 位） | Menu | Command |
| 右一（Ctrl 位） | Ctrl | Control |

💡 macOS 用户建议替换附赠的 Option 键帽以获得一致的外观。

### 6.7 多设备切换示例

场景：笔记本（蓝牙 CH1）+ 平板（蓝牙 CH2）+ 台式机（2.4G）。

| 操作 | 效果 |
| --- | --- |
| `<Fn> + <1>` | 输入切换至笔记本 |
| `<Fn> + <2>` | 输入切换至平板 |
| `<Fn> + <4>` | 输入切换至台式机（2.4G） |
| 插入 USB-C 线至台式机 | 自动切换为有线模式（可关闭该自动切换，见 11.7 节） |

### 6.8 电量查看

- 快捷查看：`<Fn> + <B>`，OLED 显示电量百分比 5 秒。
- 常驻查看：OLED 首行电量条常显。
- 精确查看：驱动软件右下角显示精确电量（±2%）。

### 8.4 层（Layer）机制

键盘共有 4 个可编程层（Layer 0 – Layer 3），任意时刻**只有一个层处于激活状态**：

- **Layer 0**：默认层，出厂标准布局。
- **Layer 1**：Fn 层。按住 `<Fn>` 时瞬时激活；短按 `<Fn> + <Fn>` 可锁定 Layer 1（OLED 显示 L1），再按一次解除。
- **Layer 2 / Layer 3**：自定义层，可整体映射为其它布局，例如游戏布局、剪辑软件布局。

| 组合键 | 功能 |
| --- | --- |
| `<Fn> + <,>`（短按） | 切换激活层 L0 → L1 → L2 → L3 循环 |
| `<Fn> + <.>`（短按） | 反向切换激活层 |
| `<Fn> + <Fn>` | 锁定 / 解锁 Fn 层 |
| `<Fn> + <U>`（长按 3 秒） | 将当前激活层设为上电默认层 |

💡 层切换时全键盘会有一次该层主色的扫光反馈，主色可在驱动中为每层指定。

### 8.5 游戏模式

| 组合键 | 功能 |
| --- | --- |
| `<Fn> + <Win>` | 锁定 / 解锁左 Win 键（锁定时 Win 键灯呈红色呼吸） |
| `<Fn> + <P>`（长按 3 秒） | 进入 / 退出全键盘游戏模式（Win 锁定 + 休眠禁用 + 报文合并关闭） |

游戏模式下：

- Windows 键失效，防止误触弹回桌面；
- 30 分钟深度休眠禁用（仅保留 5 分钟浅休眠，可再通过驱动完全禁用）；
- 蓝牙模式自动开启"高速报文模式"，轮询率由 125 Hz 提升至 166 Hz（以牺牲部分兼容性为代价，个别旧设备可能断连）。

## 9. RGB 灯光系统

### 9.1 硬件特性

- 87 颗独立贴片 LED，南向灯位，配合透光 PBT 键帽形成均匀柔光效果。
- 每颗 LED 独立 8 位 PWM 调光，1670 万色（RGB888）。
- 板载灯效引擎，全部灯效脱机运行，不占用系统资源。
- 支持与逐键自定义灯光叠加（8.3 节 `<Fn> + <F>` 开启叠加层）。

| 参数 | 范围 | 调节方式 |

### 9.4 逐键自定义

逐键自定义允许在任意预设灯效之上叠加每颗键的专属颜色：

1. 按 `<Fn> + <F>` 进入逐键模式（OLED 显示 `Per-Key`）。
2. 在驱动中（11.6 节）或使用组合键为选中的键设置颜色。
3. 再次按 `<Fn> + <F>` 退出并保存。

板载可保存 4 组灯光配置，随 4 组按键配置一并切换（见 11.7 节）。

### 9.5 音乐律动说明

音乐律动（模式 16）依赖驱动软件采集系统混音输出：

- Windows：使用 WASAPI 环回采集，无需虚拟声卡；
- macOS：需要授予驱动"音频录制"权限（系统设置 → 隐私与安全性 → 麦克风 / 音频）；
- 蓝牙 / 2.4G 模式下，律动数据经链路下发，延迟约 40–80 ms；
- 不安装驱动时，该模式退化为"随机律动"（按 1/4 拍伪随机变化）。

### 9.6 灯光与续航建议

- 追求最长续航：亮度 0，或使用模式 19 仅点亮字符；
- 常亮白光 30% 亮度是"可见性 / 续航"的平衡点（约 100 小时）；
- 呼吸、波浪等动态灯效功耗约为同亮度常亮的 1.2 – 1.6 倍；
- 电池低于 5% 时键盘自动将亮度强制降至 1 级并提示充电。

## 10. 宏与按键自定义

### 10.1 板载宏功能

键盘支持在**无驱动**环境下录制并回放宏：

1. `<Fn> + <H>`（长按 3 秒）进入宏录制模式，OLED 显示 `REC`，全部灯光转为红色微亮。
2. 依次按下要录制的按键序列（最多 64 步，支持修饰键组合，自动记录按键间隔）。
3. 按 `<Fn> + <H>` 结束录制，OLED 显示保存槽位 `M1–M8`，按对应数字选择槽位。
4. 录制完成后，`<Fn> + <1>`–`<8>`（在 Layer 2 激活时）触发对应槽位宏。

❗ 板载宏录制不记录鼠标动作；需要鼠标宏请在驱动中编辑（11.6 节）。

❗ 请勿录制包含账号、密码等敏感信息的宏。宏明文保存在键盘闪存中，任何能连接键盘的设备均可触发。

### 10.2 宏回放模式

| 模式 | 说明 |
| --- | --- |
| 单次 | 触发一次，回放一次 |
| 按住重复 | 按住宏键期间循环回放 |
| 切换 | 按一次开始循环回放，再按一次停止 |
| 涡轮 | 回放速度 ×2 / ×4 / ×8（定时精度随之降低） |

### 10.3 宏示例

**示例 1：一键输出工作邮箱签名**

```
宏名: email-sig
模式: 单次
步骤:
  1. 文本 "Best regards,"
  2. 延时 30 ms
  3. Enter
  4. 文本 "Guangzhao Yang"
  5. 延时 30 ms
  6. 文本 " — PilKB Hardware Team"
```

**示例 2：游戏连招（按住重复）**

```
宏名: combo-x
模式: 按住重复
步骤:
  1. 按下 Q（间隔 12 ms 释放）
  2. 延时 240 ms
  3. Shift+左键（间隔 12 ms 释放）
  4. 延时 180 ms
  5. 按下 E（间隔 12 ms 释放）
  6. 延时 600 ms
```

**示例 3：开发常用（打开终端并进入项目目录，切换模式）**

```
宏名: dev-term
模式: 单次
步骤:
  1. Ctrl+Alt+T        # 呼出终端
  2. 延时 600 ms        # 等待终端启动
  3. 文本 "cd ~/projects/pilkb-fw"
  4. Enter
  5. 文本 "code ."
  6. Enter
```

### 10.4 按键改写类型（板载支持）

无驱动情况下通过宏录制的"单键改写"也可实现，完整改写类型需驱动支持：

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| 无功能 | 按键禁用 | 将 Win 键改为禁用 |
| 单键 | 映射为任意单键 | CapsLock → Esc |
| 修饰键组合 | 映射为组合键 | CapsLock → Ctrl+Shift+Esc |
| 多键序列 | 依次输出多个按键 | F13 → "www." + "pilkb.com" + Enter |
| 文本 | 输出一段文本（每键 30 ms） | F14 → 常用回复话术 |
| 宏 | 绑定宏槽位 M1–M8 | — |
| 层切换 | 按键切换 / 瞬时激活某层 | — |
| 鼠标 | 鼠标按键、滚轮（移动需驱动在线） | — |
| 多媒体 | 26 种系统多媒体码 | — |
| 旋钮功能 | 仅旋钮与旋钮按下支持 | — |

### 10.5 高级：Mod-Tap 与 Tap-Hold

驱动支持将一颗物理键配置为双功能：

| 模式 | 行为 |
| --- | --- |
| Tap-Hold | 短按（< 200 ms）输出 A 键，长按输出 B 键（如短按 Esc、长按 Ctrl） |
| Mod-Tap | 短按输出字符键，按住作为修饰键持续生效 |
| 双击切换 | 双击输出 C 键，双击后按住输出 D 键 |

❗ Tap-Hold 判定窗口默认 200 ms，可在驱动 50–300 ms 间调节，影响快速连续输入的手感，请谨慎调整。

### 11.14 键盘测试工具

驱动"帮助 → 键盘测试"内置三个诊断工具，无需第三方网页即可检测：

**1. 按键测试**：虚拟键盘实时高亮按下的键，用于快速排查坏键、连击。按下并保持可查看该键的触发波形与去抖结果，波形窗口中绿色为稳定高电平、红色毛刺为被过滤的抖动。

**2. 冲突测试（NKRO）**：任意多键同按，画面显示当前能同时上报的最大键数。有线 / 2.4G 模式应显示 87（全键），蓝牙模式因 HID 协议限制显示 6，属正常现象。

**3. 轮询率测试**：以 10 秒窗口统计每秒平均报文数。建议在无其它输入的空闲系统上运行，后台占用 CPU 的程序会轻微影响测量值；正常读数：有线 / 2.4G ≥ 990 Hz，蓝牙 ≈ 125 Hz。

💡 测试结果可截图保存，联系售后时随工单附上可显著加快诊断速度。

### 12.2 热插拔轴座说明

- 全键采用热插拔轴座（Kailh 代工，支持五脚与三脚轴体混插）；
- 轴座额定插拔次数：约 200 次；
- 兼容 MX 结构轴体（Cherry MX、Gateron、TTC、Kailh 等主流三脚 / 五脚轴）；
- 不兼容 Choc 低轴（巧克力轴）与静电容轴体；
- 热插拔轴座仅支持轴体更换，不支持更换 LED（LED 焊接于 PCB）。

### 12.3 更换轴体步骤

1. 关闭键盘电源拨杆（OFF），有线连接请拔下线缆。
2. 用附赠拔键器夹住键帽两侧，垂直向上拔出键帽。带卫星轴的大键（空格、回车等）请先用拔键器拔两端，晃动缓慢提起。
3. 打开拔轴器夹口，套住轴体顶部两侧凸翼，垂直向上拔出轴体。
4. 将新轴体对准轴座（注意方向：LED 槽朝向键盘前方即"南向"），垂直均匀按下，听到轻微"咔"声即安装到位。
5. 重新安装键帽，按压四角确认稳固。

❗ 拔轴务必垂直发力，倾斜拔出可能损坏轴座卡扣；轴座损坏不在保修范围内（详见 17.3 节）。

❗ 更换轴体后如个别键无响应，多为轴体引脚弯曲，请取下轴体检查并校直引脚后重装。

### 12.4 卫星轴调校建议

出厂卫星轴已调校（钢丝润滑 + 杂音垫），若自行更换钢丝或润滑脂：

- 推荐使用 PTFE 稠化润滑脂（如 Permatex 22058 或同类）；
- 仅涂抹钢丝与定位柱摩擦处，避免接触轴心导轨；
- 拆装卫星轴时注意钢丝两端卡入平衡柱的深度一致，否则大键会出现单侧钢丝音；
- 空格键建议保留出厂调校，过润会导致回弹迟滞。

## 13. 固件升级

### 13.1 升级前准备

1. 使用 USB-C 线将键盘与电脑**有线连接**（无线模式无法升级固件）。
2. 确认键盘电量 ≥ 30%（低电量下升级有变砖风险）。
3. 关闭正在运行的其它占用键盘的软件（按键映射工具、录屏软件的按键检测等）。
4. 升级过程中请勿拔线、勿按任何按键、勿让电脑进入休眠。

### 13.2 升级步骤（通过驱动）

1. 打开 PilKB Console → 固件面板；
2. 驱动自动检测在线固件更新，点击"下载"获取固件包；
3. 下载完成后点击"升级"，键盘 OLED 显示 `DFU` 并进入刷写界面；
4. 进度条走完后键盘自动重启，OLED 显示新版本号，升级完成；
5. 建议升级后到"全局设置 → 恢复出厂 → 仅按键"执行一次配置重置（部分版本间配置格式不兼容）。

### 13.3 升级步骤（脱机救砖）

若升级中断导致键盘无法启动（OLED 不亮、电脑不识别），请执行强制恢复：

1. 按住 `<Esc>` 不放，插入 USB-C 线，5 秒后释放（键盘进入 Bootloader 模式，电脑识别为 "PilKB DFU" 设备）；
2. 打开驱动（V2.1 及以上），固件面板会出现"检测到恢复模式设备"提示；
3. 选择本地已有的固件文件（`.ukfw`）点击"恢复"；
4. 若电脑无法识别任何设备，请联系售后（17.4 节），切勿反复插拔尝试。

## 14. 保养与清洁

### 14.1 日常保养建议

| 频率 | 项目 |
| --- | --- |
| 每周 | 用干软布或气吹清理键帽表面与缝隙浮尘 |
| 每月 | 拔下键帽，清理定位板与轴体周围积尘（重点：空格、回车等大键两侧） |
| 每季 | 检查脚撑硅胶包边与底壳防滑垫，若有脱落用 3M VHB 胶重新固定 |
| 每半年 | 检查 USB-C 口内有无异物氧化；充电口触点可用无水酒精棉签轻拭（断电操作） |

### 14.2 键帽清洁

1. 关闭电源，拔下全部需要清洁的键帽（用附赠拔键器）；
2. 将键帽放入温水中，加入少量中性洗洁精，浸泡 15 分钟；
3. 用软毛刷逐个刷洗字符面与内壁；
4. 清水冲净后**彻底晾干至少 12 小时**（内壁积水会渗入轴体）；
5. 确认完全干燥后再装回。

❗ PBT 键帽耐高温，但请勿使用开水烫煮、洗碗机、烘干机清洁，剧烈热冲击可能造成微变形导致旷量。

❗ 热升华字符耐磨但并非绝对不褪色，请勿使用酒精、丙酮等有机溶剂反复擦拭字符。

### 14.3 轴体保养

- 出厂预润轴体在正常使用 2–3 年内无需补润；
- 若出现明显"沙沙"干涩声，可拆轴（需要专用开轴器）后对导轨点涂 205g0 稀油；
- 若出现双击 / 断触，优先尝试更换轴体确认是否轴体本身老化（拔插两次有时可改善触点氧化）；
- 避免在键盘周围使用加湿器直吹，湿度过高会加速轴体触点氧化。

### 14.4 外壳保养

- 阳极氧化铝外壳可用微湿软布擦拭，顽固污渍用稀释中性清洁剂；
- 避免与硬物（手表、戒指、桌面金属饰条）磕碰，氧化层划伤不可修复；
- 长期不使用请套上防尘罩，并避免阳光直射（紫外线会加速键帽泛黄，PBT 虽耐黄但非完全不黄）。

## 15. 故障排除

### 15.1 连接类

| 现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 按键无反应，OLED 不亮 | 电池耗尽 / 电源开关在 OFF | 充电 30 分钟；确认拨杆位置 |
| 有线连接电脑不识别 | 线缆仅供电不传数据 / 接口氧化 | 更换数据线（部分快充线无数据芯）；换 USB 口测试 |
| 蓝牙搜不到设备 | 未进入配对模式 / 通道已存满 | 长按 `<Fn> + 通道键` 3 秒确认蓝灯快闪；删除旧配对后重试 |
| 蓝牙连上但几秒断开 | 系统蓝牙省电策略 / HID 设备数超限 | 系统蓝牙设置中关闭"允许计算机关闭此设备以节约电源"；删除不用的蓝牙设备 |
| 蓝牙输入延迟明显、丢字 | 2.4 GHz 干扰（WiFi 路由器、USB3 设备） / 轮询 125 Hz 属正常 | 键盘远离路由器与 USB3 硬盘；改用 2.4G 或有线模式 |
| 2.4G 接收器插上无反应 | 接收器与键盘失配 / 接口供电不足 | 按 6.5 节重新对码；换主板后置 USB 口 |
| 2.4G 频繁掉线 | USB3.0 端口干扰 / 接收器过远 | 使用附赠延长线将接收器移近键盘；避免插在 USB3.0 蓝色接口旁 |
| 切换通道后 OLED 显示 exclamation | 目标通道无配对记录 | 对该通道重新执行配对 |
| 蓝牙下多媒体键无效 | 部分老系统不支持 AVRCP/HID over GATT | 属系统限制；升级系统或改用有线 / 2.4G |

### 15.2 输入类

| 现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 某一键无输出 | 轴体未插到位 / 轴体损坏 | 重插该轴；更换附赠备用轴验证 |
| 某一键连续输出（连击） | 去抖过短 / 轴体触点氧化 | 驱动将去抖调至 8–10 ms；更换轴体 |
| 按键断触（长按断续） | 轴体弹簧疲劳 / 触点污损 | 更换轴体 |
| 打字出现错位字符 | 开启了 Layer 2/3 布局 / 系统输入法异常 | 按 `<Fn> + <,>` 回到 L0；检查系统键盘布局设置 |
| 修饰键全部失灵 | 层被锁定在异常配置 | `<Fn> + <X>` 长按恢复出厂按键配置 |
| Win 键无效 | 游戏模式锁定 Win | `<Fn> + <Win>` 解锁 |
| 大小写切换相反 | CapsLock 被改写 | 检查驱动按键面板中 CapsLock 设置 |
| 组合键识别不全 | 蓝牙 125 Hz 下 6 键以上同按 | 属 HID 协议限制；改用 2.4G / 有线（NKRO） |
| 宏不触发 | 宏绑定在其它层 / 容量溢出 | 确认当前激活层；检查驱动宏容量提示 |

### 15.3 灯光与显示类

| 现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 个别键灯不亮 | 该键 LED 故障 / 逐键层被设为黑色 | 检查驱动逐键设置；若 LED 损坏联系售后 |
| 灯光全灭 | 亮度被调至 0 / 低电量强制降级 | `<Fn> + <W>` 调高亮度；充电 |
| 灯效卡住不动 | 灯效引擎异常 | 有线连接后驱动内"重启灯效引擎"，或重新上电 |
| OLED 花屏 / 残影 | 低温环境响应变慢 / 固件 bug | 恢复常温观察；升级最新固件 |
| OLED 完全黑屏但键盘可用 | OLED 排线接触不良 / 屏幕故障 | 联系售后检修（OLED 属保修范围） |
| 充电指示灯不亮 | 电量已满 / 线缆仅供电 | 查看 OLED 电量是否 100%；更换数据线 |

### 15.4 电池与充电类

| 现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 充电极慢（>8 小时） | 使用了仅 0.5A 以下供电口 / 边充边用高亮灯效 | 换 5V/1A 以上适配器；关灯充电 |
| 电量显示大幅跳动 | 电池校准漂移 | 将电量用至自动关机，再一次性充满校准 |
| 续航明显低于标称 | 高亮度动态灯效 / 电池老化 | 参照 4.3 节组合排查；使用超过 2 年属正常衰减 |
| 电池鼓包、外壳隆起 | 电池故障 ⚠️ | 立即停用并联系售后，勿继续充电 |

### 15.5 驱动类

| 现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 驱动识别不到键盘 | 未装驱动 / HID 占用 / 权限 | 重装驱动；macOS 下授予"输入监控"权限；换 USB 口 |
| 驱动设置保存后无效 | 未点击"应用" / 固件版本过低 | 检查底部"未保存更改"提示；升级固件 |
| 云同步失败 | 网络问题 / 账号未登录 | 检查网络代理；重新登录 |
| 音乐律动无反应 | 权限未授予 / 音频为独占模式 | macOS 授予音频权限；关闭其它软件的独占音频占用 |

### 15.6 何时联系售后

出现以下情况请勿自行处理，直接联系售后服务：

1. 电池鼓包、异响、异味；
2. 进液后无法恢复；
3. OLED / 旋钮物理故障；
4. 脱机救砖失败；
5. PCB 焊点脱落（非热插拔轴座范围内的其它元件）。

## 16. 常见问题（FAQ）

**Q1：A87 Pro 可以给 iPad / 安卓平板用吗？**
可以。推荐蓝牙模式；如平板支持 OTG，也可用 2.4G 接收器（iPad 需 USB-C 口且系统 iPadOS 13+）。

**Q2：游戏时用哪个连接模式最好？**
优先有线，其次 2.4G（1000 Hz 轮询，延迟约 1–4 ms）。蓝牙（125 Hz）适合回合制、休闲游戏，不建议用于 FPS 竞技。

**Q3：为什么我的键盘凌晨自动关了？**
深度休眠生效（默认 30 分钟无操作）。在驱动"性能面板"将深度休眠设为"从不"可保持常开，但会显著增加耗电。

**Q4：换键帽会影响保修吗？**
不会。正常插拔键帽属于允许的用户操作。但因此造成的键帽卡扣损坏、卫星轴钢丝变形不在保修范围。

**Q5：换轴后个别键变肉（手感发闷）怎么办？**
多为轴体未完全插平，或三脚轴的塑料定位脚与五脚轴座存在旷量。重新垂直插紧；三脚轴建议加装转接垫片。

**Q6：能同时连着有线又开蓝牙给手机用吗？**
可以，三者可同时在线。注意有线模式下若"有线锁定开关"在 LOCK 位则无线被禁用。

**Q7：键盘可以关灯纯用吗？**
可以，亮度 0 级即完全熄灭，续航也最长。

**Q8：为什么蓝牙打字偶尔丢一个字？**
蓝牙 HID 协议在 125 Hz 轮询与低功耗调度下，快速连续输入时可能丢失按键。将键盘靠近主机、远离 2.4 GHz 干扰源，或改用 2.4G/有线。

**Q9：旋钮拧起来一格一格的，坏了吗？**
不是故障。编码器旋钮本身是有刻度（detent）的手感设计，每格对应一档音量（或自定义步长）。

**Q10：我可以把空格键换成分离空格（split spacebar）吗？**
不可以。PCB 与定位板为标准 6.25U 单空格开孔，不支持分体空格改装。

**Q11：键盘上的宏会被游戏反作弊判定为外挂吗？**
板载宏以标准 HID 键盘报文输出，与物理按键一致，主流反作弊不会因输入报文本身判定异常。但使用宏获取不正当游戏优势可能违反游戏服务条款，由此产生的账号问题与本产品无关。

**Q12：OLED 上显示的温度是电池温度吗？**
是主控 PCB 附近温度，反映腔内温度，供参考。长时间满亮 RGB 下显示 40–45 ℃ 属正常。

**Q13：为什么说明书说续航 200 小时，我只有 60 小时？**
标称值为灯光全关 + 蓝牙模式。请检查：灯效亮度、是否 2.4G 模式、深度休眠是否被禁用、游戏模式是否常开。

**Q14：想给笔记本和台式机共用一套键盘，怎么连最省事？**
笔记本走蓝牙 CH1，台式机插 2.4G 接收器，`<Fn> + <1>` / `<Fn> + <4>` 一键切换。

**Q15：键盘进了一点点水还能用，需要送修吗？**
若仅少量清水且已阴干，功能正常可继续使用，但建议持续观察几天。进液对 PCB 的腐蚀是渐进过程，若后续出现按键异常请尽快送修，并在送修时说明进液史。

**Q16：键盘可以边充电边使用吗？**
可以，且这是推荐用法。有线模式下按键报文走线缆、灯光由 USB 供电，不消耗电池。

**Q17：可以给轴体加装 O 型消音圈吗？**
可以（MX 轴通用 0.2 mm / 0.3 mm 规格均兼容）。注意加装后键程缩短约 0.3 mm，触发可能变早；本机轴体行程余量足够，不会影响触发，但提前段落轴手感会变化。

**Q18：把键盘放在腿上或沙发扶手上用，连接会断吗？**
蓝牙与 2.4G 在无遮挡 1 m 内一般稳定；人体遮挡会明显衰减 2.4 GHz 信号，姿态变化导致的偶发延迟属正常现象。

**Q19：电脑开机进 BIOS 时键盘能用吗？**
能用。键盘的 Interface 0 支持 HID Boot Protocol，BIOS / 安全模式 / 系统安装界面下基础键入可用（多媒体键与 Fn 层部分功能除外）。

**Q20：驱动必须常驻后台吗？**
不需要。所有改键、宏、灯效均可写入板载，配置完成后可完全卸载驱动。仅"音乐律动""鼠标宏""云同步"需要驱动在线。

**Q21：在没装驱动的另一台电脑上，自定义按键还生效吗？**
生效。配置保存在键盘内部闪存，与所连电脑无关，甚至切换到手机 / 平板同样生效。

**Q22：家里换了新路由器（Wi-Fi 6E）后 2.4G 频繁掉线怎么办？**
新路由器若将 2.4 GHz 频段带宽设为 40 MHz 且占用固定信道，会与键盘私有协议冲突。将路由器 2.4 GHz 信道带宽改回 20 MHz，或换信道（推荐 1 / 6 / 11 以外），并使用附赠延长线把接收器移近键盘。

**Q23：`<Fn> + <X>` 恢复出厂会清掉蓝牙配对记录吗？**
不会，只重置按键配置与层设置。蓝牙配对记录需按 6.4 节逐通道长按 8 秒清除；完整擦除请用驱动的"恢复出厂 → 全部"。

**Q24：为什么我的 Esc / 方向键键帽颜色和官方图不一致？**
雪山限定版与曜石版配有差异键帽组，出厂预装可能为标准键帽，附赠键帽袋内为限定配色版本，可自行更换。

**Q25：接收器丢了可以单独补购吗？**
可以，联系售后购买同型号接收器，到手后按 6.5 节对码即可。不同批次接收器与键盘固件完全兼容。

**Q26：锂电池安全吗？会不会起火？**
电芯通过 UN38.3 与 CCC 认证，配有过充、过放、过流、短路四重保护电路。正常使用与充电是安全的；请遵守 2.2 节注意事项，尤其是不要使用超规格电源。

**Q27：咖啡 / 奶茶洒进键盘怎么处理？**
立即断电关机 → 倒置沥干 → 拔下受影响区域键帽 → 用无水酒精棉签清理可见残渍 → 阴干 72 小时再通电测试。含糖饮料干涸后会腐蚀触点并使轴体发黏，强烈建议直接送修做专业清洗（进液属非保修项目，收费清洗）。

**Q28：空格键左右轻晃有旷量，正常吗？**
卫星轴大键允许存在轻微旷量（出厂控制在 0.2 mm 内）以保证顺滑度；若晃动明显且伴随钢丝音，可能是卫星轴钢丝脱位，可拆键帽检查或送修。

**Q29：想再静音一点，除了换静音轴还有什么办法？**
三个低成本方案：① 灯光与报文无关但轴体触底声是主噪音源，可在定位板与 PCB 之间补一层 2 mm Poron（需拆解，注意保修条款 17.3）；② 桌面下铺厚桌垫吸收共振；③ 将键盘平放（收起脚撑），敲击力度自然减小。

**Q30：手汗多，键帽会不会很快打油？**
PBT 键帽抗打油性远优于 ABS，正常手汗使用 3–5 年无肉眼可见打油。建议手汗大时定期用微湿布擦拭（断电状态），避免汗盐长期残留腐蚀字符层。

### 附录 H：健康使用与人体工学建议

机械键盘是生产力工具，正确使用姿势与合理休息同样重要。本附录内容参考通用职业健康指南整理，不能替代专业医疗建议。

#### H.1 打字姿势要点

| 要点 | 说明 |
| --- | --- |
| 前臂与地面平行 | 调整椅高或桌面高度，肘部约呈 90°–100° |
| 手腕自然平放，不上翘不下压 | 避免长时间腕部背伸；本键盘前缘厚度 18 mm，多数用户无需掌托 |
| 手指微屈悬浮 | 避免手腕压在桌缘，让手指而非手腕发力 |
| 显示器顶部与视线齐平 | 减少低头，缓解颈肩连锁紧张 |
| 肩膀放松下沉 | 检查是否有耸肩敲键盘的习惯 |

#### H.2 键盘倾角选择

| 设置 | 建议场景 |
| --- | --- |
| 脚撑收起（平放，约 4°） | 桌面偏高或椅面偏低时首选，腕部最中立 |
| 一段脚撑（约 6°） | 桌高适中，习惯传统键盘坡度 |
| 二段脚撑（约 10°） | 仅建议观察者位 / 展示用途，长时间打字会加大腕部背伸 |
| 负倾角（前脚撑展开，-4°） | 搭配低桌或升降桌坐姿偏低时，对腕部最友好 |

❗ 不要同时展开前后脚撑把键盘顶成"跷跷板"，中间悬空会产生共振杂音并加速定位板形变。

#### H.3 休息与练习

- 遵循"20-20-20"原则：每 20 分钟看 20 英尺（约 6 m）外 20 秒，缓解眼部与手部持续紧张；
- 每小时起身活动 3–5 分钟，做腕部伸展：掌心向外轻拉手指保持 15 秒、双手握拳后五指张开重复 10 次；
- 出现持续麻木、刺痛（尤其夜间痛醒）应暂停使用并就医，勿强行"适应"；
- 建议开启驱动的"使用统计"，留意每日按键量与高频键分布，及时调整改键减少小指负荷（参见附录 F.1）。

#### H.4 环境提示

| 项目 | 建议 |
| --- | --- |
| 桌面照度 | 键盘区 ≥ 300 lx，避免仅靠背光在暗环境长时间输入 |
| 噪声环境 | 图书馆 / 深夜宿舍建议使用雪狐静音轴或将键盘调为低亮度静音模式 |
| 温度 | 低于 0 ℃ 环境轴体润滑脂粘度上升，手感会变"钝"，属正常物理现象，回温后恢复 |

### 附录 I：运输、存放与转让指引

#### I.1 日常移动（通勤携带）

1. 关闭电源拨杆（OFF），防止包内误触唤醒耗电；
2. 取下 2.4G 接收器放入键盘顶部磁吸收纳仓；

| 项目 | 要求 |
| --- | --- |
| 电量 | 降至 30% 以下（航空托运要求，陆运亦建议） |
| 电源 | 拨杆置 OFF |
| 包装 | 使用原厂泡棉；无原包装时用气泡膜包裹整机并填满空隙，键帽一侧朝上 |

1. 电量充至 40%–60% 后关机存放；

#### J.1 HID 接口与报文

键盘在有线 / 2.4G 模式下枚举三个 HID 接口：

| 接口 | 用途 | 报文长度 |
| --- | --- | --- |
| Interface 0 | 标准键盘（Boot Protocol 兼容） | 8 字节（标准 NKRO 报文为 16 字节） |
| Interface 1 | 多媒体 / 消费者控制键 | 可变长 |
| Interface 2 | 厂商自定义（驱动通信通道） | 64 字节 Feature Report |

**标准 8 字节键盘报文结构：**

```
字节 0: 修饰键位图
        bit0 LCtrl, bit1 LShift, bit2 LAlt, bit3 LGUI,
        bit4 RCtrl, bit5 RShift, bit6 RAlt, bit7 RGUI
字节 1: OEM 保留（0x00）
字节 2–7: 当前按下键值（Usage ID），最多 6 键；无键按下时全 0
```

**厂商通道（Interface 2）命令帧（部分）：**

| 命令码 | 名称 | 说明 |
| --- | --- | --- |
| 0x01 | GET_VERSION | 返回固件版本、序列号 |
| 0x10 | GET_BATTERY | 返回电压 mV 与百分比 |
| 0x20 | READ_CONFIG | 读板载配置组（64 字节分页） |
| 0x21 | WRITE_CONFIG | 写板载配置组 |
| 0x22 | SAVE_CONFIG | 将 RAM 配置提交至闪存 |
| 0x30 | LED_DIRECT | 直接驱动全键 RGB（逐键 3 字节，分 5 帧） |
| 0x31 | LED_MODE | 切换预设灯效 |
| 0x40 | DFU_ENTER | 进入 Bootloader（救砖用，等同按住 Esc 上电） |
| 0x50 | OLED_DRAW | 向 OLED 推送一帧 128×32 位图（512 字节，分 9 帧） |
| 0xF0 | ECHO | 链路测试 |

命令帧通用格式：

```
字节 0: 命令码
字节 1: 序号（响应中原样返回，用于配对请求响应）
字节 2: 数据长度 N (0–59)
字节 3 – 3+N-1: 数据
末尾 1 字节: XOR 校验（自字节 0 起异或）
```
